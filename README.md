# Periodic Table

A lightweight, single-page periodic table with a dark theme and purple accents.

## Live site

Visit [the periodic table](https://8ball8b.github.io/periodic-table/).

## Features

- All 118 elements, with atomic numbers, symbols, and atomic masses.
- Search by element name, symbol, or atomic number; filter by category.
- Select an element to view details and a draggable, 3D-style atom illustration.
- Responsive layout with no external libraries or build step.

The atom is a simplified illustration, not a scale-accurate physical model. Its nucleus is visually capped to keep rendering smooth.

## Run locally

Open `index.html` in a modern web browser. No installation or build tools are required.
